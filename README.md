# Jaishree Jewellers — Haute Joaillerie & Fine Jewelry

An ultra-premium, modern fine jewelry e-commerce experience built with React 19, Vite, Tailwind CSS v4, GSAP, and Framer Motion. Inspired by luxury aesthetics and cinematic craftsmanship showcases.

## ✨ Key Features

- **Cinematic Hero Experience**: Smooth zoom/pan intro animations with GSAP CustomEase, video integration, and dynamic scroll indicators.
- **Interactive Jewelry Catalog**: Curated collections of Diamond Rings, Pendants & Charms, Haute Earrings, and Solid Gold Link Bracelets.
- **Product Quick View Modal**: High-resolution gallery carousel, gemological specifications (metals, diamond clarity, carat weights, certifications), and instant Add to Cart.
- **Live Cart Drawer**: Sliding drawer with real-time quantity adjustment, subtotal calculation, tax, and free insured shipping threshold.
- **End-to-End Checkout Modal**: Simulated encrypted checkout flow with card validation, security trust badges, and order summary.
- **Dynamic Collections Slider**: 5-slide interactive suite showcase with synchronized dual-image vertical unrolling clip-path reveals.
- **Responsive & Accessible**: Seamlessly adapts from ultra-wide displays down to mobile devices with custom drawer navigation.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Vanilla CSS architecture)
- **Animations**: GSAP (ScrollTrigger, CustomEase) + Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Run Locally in Development
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
